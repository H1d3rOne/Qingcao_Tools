# 咸鱼管理页商品列表视觉优化设计

## 背景

当前 `web-vue/src/views/xianyu/components/XianyuManageItemsPanel.vue` 的商品管理列表以纯文本信息为主，虽然信息完整，但商品识别效率偏低：

- 商品缺少封面图，浏览时不够直观
- 价格虽然已着色，但视觉聚焦不足
- 标题、ID、详情、操作区横向排布较平，商品层级不够明确

本次优化仅针对“商品管理”列表区的视觉与排版，不修改接口协议，不扩大到其他 tab。

## 目标

1. 在商品管理列表中展示商品封面图
2. 将价格升级为更醒目的暖色高亮胶囊
3. 优化信息层级与排版，使列表保持紧凑但更像“商品列表”而不是“文本列表”
4. 在桌面端和移动端都保持可读性和稳定布局

## 非目标

- 不调整后端接口
- 不变更 `XianyuManageItem` 数据结构
- 不修改商品编辑、删除、多数量发货的行为逻辑
- 不修改自动发货 / 运行状态等其他管理子面板

## 现有数据与约束

前端已有 `XianyuManageItem` 字段：

- `item_id`
- `item_title`
- `item_price`
- `item_image`
- `item_status`
- `item_detail`
- `multi_quantity_delivery`

因此封面图直接使用 `item_image`，无需新增接口字段。

## 方案选择

已与用户确认采用：

- **布局方向：紧凑列表**
- **视觉方案：A（封面左侧 + 价格胶囊）**
- **价格风格：推荐暖色系**

不采用的方向：

- 价格竖栏方案：视觉更重，偏后台报表感
- 顶部价格高亮条方案：更轻，但价格聚焦不如胶囊明显

## 目标布局

每个商品条目拆为三个视觉区域：

### 1. 左侧封面区

- 显示 `item_image`
- 使用固定宽高的小图，避免不同商品图片导致列表高度抖动
- 圆角展示，贴合管理面板的柔和风格
- 图片容器固定比例，图片使用 `object-fit: cover`
- 当 `item_image` 为空时，显示浅色占位块和简洁占位文案/图形

### 2. 中间内容区

按视觉优先级排序：

- 第一行：商品标题 + 价格胶囊
- 第二行：商品 ID
- 第三行：商品详情

细节要求：

- 标题最多显示 2 行，避免长标题撑乱布局
- ID 保持小型标签样式，延续现有系统感
- 商品详情最多显示 2 行，超出截断
- 标题区与价格胶囊顶部对齐，保证首屏扫描稳定

### 3. 右侧操作区

保留现有交互能力：

- 多数量发货开关
- 编辑按钮
- 删除按钮

但需要做更稳定的纵向对齐：

- 桌面端右侧固定为操作区
- 操作按钮组与开关在视觉上归为一个独立列
- 避免内容区高度波动时按钮位置跳动太明显

## 价格高亮规范

价格采用暖色系胶囊设计，而不是普通文字高亮。

### 样式要求

- 使用暖色背景（橙/红橙系浅底）
- 使用更醒目的暖色主文字
- 字号高于当前价格文本
- 字重提升为强调等级
- 数字使用稳定的数值排版方式，减少视觉抖动
- 允许轻微阴影或渐变，但保持克制，不能变成营销风格卡片

### 空价格降级

当 `item_price` 为空时：

- 显示“未设置价格”
- 不使用强高亮胶囊
- 使用弱化、低对比的占位样式，避免与真实价格竞争注意力

## 视觉风格要求

总体方向：**稳重的管理面板 + 明确的商品感**。

要求：

- 不做电商首页式大卡片
- 不引入过重阴影、复杂装饰或花哨边框
- hover 态延续现有轻量边框与背景变化
- 商品封面图、价格、标题形成清晰主层级
- 按钮和开关保持管理工具的理性气质

## 响应式策略

### 桌面端

- 结构为：左图 / 中间内容 / 右侧操作
- 价格胶囊位于标题区右侧或同一信息组中，确保一眼可见
- 内容区占据主要宽度，操作区保持固定感

### 移动端

改为纵向布局，原则：

- 封面图在上或左上，避免过窄时压缩内容
- 标题、价格、ID、详情顺序保持一致
- 操作区移到底部，按钮和开关顺序清晰
- 避免横向拥挤导致价格胶囊、标题、按钮互相挤压

## 组件改动范围

主要修改文件：

- `web-vue/src/views/xianyu/components/XianyuManageItemsPanel.vue`

可能同步更新：

- `web-vue/src/views/xianyu/components/XianyuManageItemsPanel.spec.ts`

## 实现思路

1. 在列表项模板中新增封面图区
2. 将商品主体从单层文本改为更明确的结构块：媒体区 / 信息区 / 操作区
3. 为价格增加胶囊样式类，并区分“真实价格”和“未设置价格”状态
4. 为空图片增加占位渲染
5. 调整 CSS：
   - 列表项网格/弹性布局
   - 图片尺寸与裁切
   - 标题、详情多行截断
   - 价格胶囊视觉层级
   - 移动端断点布局
6. 更新组件测试，覆盖：
   - 有图渲染
   - 无图占位
   - 价格高亮样式分支
   - 现有编辑/删除/开关交互仍可正常工作

## 错误与降级处理

- 图片地址为空：显示占位块，不报错
- 图片加载失败：前端允许展示空态/占位外观，不影响其他信息和操作
- 价格为空：使用弱化文案，不占用高优先级强调样式

## 测试策略

### 组件测试

补充或调整 `XianyuManageItemsPanel.spec.ts`，验证：

- 商品封面图存在时正确渲染
- 无封面图时展示占位元素
- 有价格时展示高亮价格区域
- 无价格时展示弱化占位价格文案
- 既有按钮和开关行为不回归

### 手动验证

在真实管理页确认：

- 列表整体更易扫读
- 长标题不破坏布局
- 详情截断正常
- 价格胶囊醒目但不过于跳脱
- 桌面与移动宽度下均无明显拥挤

## 验收标准

满足以下条件即可认为完成：

1. 商品管理列表显示封面图
2. 空图时有稳定占位样式
3. 价格以暖色高亮胶囊显示
4. 无价格时采用弱化展示
5. 标题、ID、详情、操作区层级更清晰
6. 现有商品管理交互不受影响
7. 组件测试与构建验证通过
