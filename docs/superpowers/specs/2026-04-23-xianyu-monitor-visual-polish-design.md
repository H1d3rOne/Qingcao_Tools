# 咸鱼监控页卡片精修与预览箭头设计

## 背景

监控页已经完成两项核心能力：

1. 右侧“最近命中”默认折叠，点击后再展开预览
2. 左侧任务列表标题已做基础高亮

当前还可以继续做一轮轻量精修：

- 左侧任务卡片的信息层级还可以更稳
- 展开/收起预览按钮目前只有文本，没有方向提示
- 用户希望在不改变整体结构的前提下，把显示效果再打磨一轮
- 本轮完成后需要只做本地提交，不推远端

## 目标

1. 进一步优化左侧监控任务卡片的显示层级
2. 为“展开预览 / 收起预览”增加小箭头图标
3. 保持监控页整体风格克制、稳重、不花哨
4. 完成后进行本地 git commit

## 非目标

- 不改监控接口
- 不改监控任务数据结构
- 不新增复杂动画、抽屉、分页或二级交互
- 不 push 远端
- 不重做整个监控页布局

## 已确认选择

- 视觉方向：**轻量精修（方案 A）**
- 展开区保留当前文本按钮形式，只补充方向箭头
- 提交方式：**仅本地 commit**

## 方案选择

采用方案：**轻量卡片精修 + 文本按钮箭头化**。

不采用的方向：

- 重状态卡方案：视觉过重，容易偏离当前页面风格
- 仅加箭头不做卡片层级调整：收益太小，不足以覆盖“显示效果再调整”的目标

## 目标设计

### 1. 左侧任务卡片层级精修

每个任务卡片保持当前结构，但进一步拉开三层关系：

- 第一层：任务标题
- 第二层：关键词
- 第三层：时间 / 命中数 / 状态

### 标题

- 维持当前较强权重
- 在 active 状态下保留高亮色
- 标题区域可稍微增加行高和字距稳定性，使扫描更轻松

### 关键词

- 保持可读，但继续弱于标题
- 如果合适，可给关键词增加一点点字重或稳定色值，而不是过灰

### 底部信息

- 时间与命中数维持次级信息
- active 状态下可以做轻微提亮，但不能超过标题

### 卡片整体

- 非激活卡片保持轻量悬停反馈
- 激活卡片继续使用轻强调背景与边框
- 可适度增强卡片内边距、圆角或阴影一致性，但不做大改版

## 2. 展开/收起预览按钮箭头化

### 交互形式

在当前按钮文案基础上增加一个小箭头图标：

- 折叠时：`展开预览` + 向下箭头
- 展开时：`收起预览` + 向上箭头

### 表现要求

- 箭头尺寸小于正文，不喧宾夺主
- 与按钮文字在同一行对齐
- 可加轻微方向切换过渡，但必须克制
- 不需要引入复杂旋转动画

### 设计要求

- 仍然保持为轻量按钮，不改成重胶囊或大面积主色按钮
- 与旁边“刷新”按钮形成清晰但不过度抢眼的对比

## 3. 风格边界

整体仍然遵循：

- 管理工具式 UI
- 信息优先，不做营销感装饰
- 小幅增强层级，不做大幅样式跳跃
- 每一项变化都要服务于“更易扫读”而不是“更显眼”

## 改动范围

主要文件：

- `web-vue/src/views/xianyu/components/XianyuMonitorPanel.vue`

可能同步更新：

- `web-vue/src/views/xianyu/components/XianyuMonitorPanel.spec.ts`

## 实现思路

### 1. 任务卡片样式微调

重点样式类：

- `.mp-task`
- `.mp-task--active`
- `.mp-task__name`
- `.mp-task__keyword`
- `.mp-task__footer`
- `.mp-task__status`

目标是让 active / normal / secondary 信息分层更明确。

### 2. 增加箭头图标

在 `XianyuMonitorPanel.vue` 中为预览按钮加图标，优先使用现有 Element Plus icon 体系中的轻量箭头图标，避免自定义 SVG 增加复杂度。

例如：

- 折叠：`ArrowDown` / `CaretBottom`
- 展开：`ArrowUp` / `CaretTop`

实际采用哪个图标，以与当前页面风格最协调为准，但必须保证方向语义清晰。

### 3. 文本与图标排版

按钮内容建议为：

- 图标 + 文案
- 或 文案 + 图标

只要保证：

- 对齐自然
- 切换时不抖动
- 在真实页面中一眼能理解是展开/收起

## 测试策略

### 组件测试

补充或调整 `XianyuMonitorPanel.spec.ts`，至少验证：

1. 折叠状态下按钮存在箭头图标容器或对应结构
2. 展开后文案与状态切换仍正确
3. 原有折叠/展开/切换任务逻辑不回归

### 手动验证

在真实页面确认：

- 任务卡片视觉层级比现在更清晰
- active 卡片更容易识别，但不过于刺眼
- 展开按钮带箭头后更易理解
- 展开与收起状态切换自然

## 提交策略

本轮完成后：

1. 跑与本次改动直接相关的测试
2. 跑前端构建
3. 执行本地 `git commit`

明确不做：

- `git push`
- PR 创建

## 验收标准

满足以下条件即可认为完成：

1. 左侧任务卡片层级较当前更清晰
2. 任务标题、关键词、底部信息的视觉优先级更稳定
3. 展开/收起预览按钮包含明确方向箭头
4. 折叠逻辑本身不回归
5. 目标测试通过
6. 构建通过
7. 完成本地 commit
